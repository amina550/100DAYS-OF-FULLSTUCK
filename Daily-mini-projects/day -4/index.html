🧠 Under the Hood – ES6+ Concepts

The spread operator ... shallow-copies every key from one object into a new one. User choices sit on top of defaults — later keys win. 


          


          

            

              Destructuring lets you unpack values from objects or arrays into
              distinct variables in one clean line, with optional defaults.
            

            

          


          

            

              The rest parameter ...rest collects all remaining
              arguments / properties into a single array or object. Useful for
              variadic functions and omitting keys.
            

            

          


          

            

              ⚠️ Spread is shallow. Nested objects are still shared by reference.
              Mutating a nested property on the "copy" also changes the original!
