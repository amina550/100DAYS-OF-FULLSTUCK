🧠 How the Array Methods Work Here

filter()

Returns a new array of only the items that pass a test function. Used to keep only employees whose role matches the active filter.

// Keep only Designers
const designers = users.filter(u => u.role === "Designer");
// [{ name: "Alice", role: "Designer", ... }, ...]

map()

Transforms every item and returns a new array of the same length. Used to convert each user object into an HTML table-row string.

const rows = visible.map((u, i) =>
  `<tr><td>${i+1}</td><td>${u.name}</td>...</tr>`
);
tableBody.innerHTML = rows.join("");

reduce() ← the tricky one

reduce walks through every item, passing a running accumulator from one iteration to the next. It returns a single value — here: the total salary sum.

// accumulator starts at 0 (the second argument)
const totalSalary = visible.reduce((acc, user) => {
  return acc + user.salary;   // acc grows with each iteration
}, 0);                        // ← initial value (NEVER forget this!)

💡 Forgetting the initial value (0 here) is the #1 mistake. Without it, the first element becomes the accumulator and numeric addition silently becomes string concatenation.
