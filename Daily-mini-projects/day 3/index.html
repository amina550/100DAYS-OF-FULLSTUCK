📚 e.target vs e.currentTarget

e.target

The exact element the user clicked on. It bubbles up from the innermost element that received the event.

If you click the badge inside the card, e.target is the <span class="badge">.

e.currentTarget

The element where the event listener is attached. It stays the same regardless of where inside it you click.

Because the listener lives on <body>, e.currentTarget is always <body>.

💡 Analogy: Imagine a building (currentTarget = the building). You knock on a specific room door (target = the room). The guard at the building entrance always intercepts the knock, but knows exactly which room you knocked on.
